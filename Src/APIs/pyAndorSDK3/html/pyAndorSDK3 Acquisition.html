Saves the current Acquisition instance image data to fits file

Parameters

  • path (str) – The destination file path (including filename) to save to

  • overwrite_if_exist (bool, default=False) – Flag to overwrite the file name if it already exists

Raises

  • NotImplementedError – Raised if the ‘save’ package is not installed

  • OSError – Raised when save destination path already exists but have not set overwrite_if_exists to True
